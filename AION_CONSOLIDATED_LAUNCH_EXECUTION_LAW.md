# AION CONSOLIDATED LAUNCH & EXECUTION LAW

## AGENT-ONLY RUNTIME AMENDMENT — 2026-09-20

This amendment is part of this same law. It supersedes any older operational
instruction in this law, the Roadmap, Continuity Directive, Current State or
repository documentation that makes human participation a prerequisite for
AION runtime or commercial progress.

AION commercial runtime is AI-agent-first and machine-to-machine.

A human response, design-partner conversation, operator review, manual
participation classification, manual usefulness acknowledgement, or human buyer
confirmation MUST NOT be required for discovery, request intake, qualification,
routing, execution, outcome acceptance, VUO establishment, payment/settlement
after rail activation and within authorized bounds, repeat use, learning, or
scaling.

Primary loop:

```
AGENT DISCOVERS AION
-> MACHINE-READABLE REQUEST
-> AUTHENTICATED MACHINE AUTHORITY
-> ELIGIBLE SUPPLY
-> ROUTE / QUOTE
-> MACHINE PAYMENT AUTHORIZATION / RESERVE WHERE REQUIRED
-> EXECUTE
-> MACHINE-VERIFY REQUEST CONTRACT
-> VUO
-> SETTLE
-> RECEIPT
-> RETURN / REPEAT
-> CM/VUO
-> SCALE
```

VUO means request-contract satisfaction supported by machine-verifiable
evidence. For deterministic/fixed capabilities, a successful
capability-specific verifier plus delivery to the authenticated requesting
agent is sufficient. No separate usefulness attestation is required.

For subjective capabilities, the requesting agent must provide or agree to
machine-checkable acceptance criteria or an agreed verifier before execution.
AION must not solve subjectivity by inserting a mandatory human approver.

Human Gates are owner control-plane gates only:
- production deploy / rollback;
- production database migration;
- production config / secrets / AutoDeploy changes;
- destructive infrastructure operations;
- initial activation or material expansion of real-money rails and risk limits;
- other legally required owner actions.

After a payment rail and deterministic limits are owner-authorized,
individual machine transactions inside those limits MUST NOT require
per-transaction human approval.

Human outreach and conversation may be used as optional research. They are
never launch-critical, never required for revenue, and never substitutes for
agent-native acquisition.

Legacy Package 5 / Ambassador / operator-review proof is historical or optional
analytics, not current launch authority.

Evidence exists to operate safely, settle correctly, learn and audit. Evidence
collection MUST NOT become a substitute for shipping the agent economy.
